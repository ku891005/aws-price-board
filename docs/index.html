방법 1 · 브라우저에서 직접 받기

가격표는 RDS 약 17MB, EC2 약 100MB 이상입니다. 창을 열면 RDS → EC2 순서로 자동 진행되며, 중간에 중단할 수 있습니다.

방법 2 · 내려둔 가격표 파일에서 불러오기

이미 받아둔 원본 가격표(_pricelist_rds_ap-northeast-2.json 같은 AWS index.json)나, 이 도구가 만든 rds.json·ec2.json을 선택하면 브라우저 안에서 다시 파싱합니다. 파일은 어디로도 전송되지 않습니다.

방법 3 · 파이썬 수집기로 갱신 (권장)

리포지토리 폴더에서 아래를 실행하면 RDS·EC2 전부 갱신되고 단일 파일까지 다시 만듭니다.

python scripts/collect_prices.py --refresh --xlsx
python scripts/build_standalone.py
